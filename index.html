How the dashboard works

Central prototype database: outreach records are loaded from the Render backend so different devices can work with the same dataset. This pilot should use only non-identifiable program data.
The dashboard starts empty. When a volunteer saves a new outreach record, the Overview updates immediately. High and Medium records are also added automatically to the Follow-up Tracker. Low priority records remain in the Overview but are not added to follow-up. If a record was entered by mistake, it can be deleted from the Overview or Follow-up Tracker. Clear All Data resets the entire saved outreach dataset after confirmation.
